# EDGEWORK live chat setup

The prototype works immediately in local browser mode. To make chat live across users/devices:

1. Create a Supabase table named `edgework_chat` with columns:
   - `id` bigint generated by default as identity primary key
   - `room` text not null
   - `name` text not null
   - `message` text not null
   - `created_at` timestamptz default now()
2. Enable Realtime for `edgework_chat`.
3. Add RLS policies that allow authenticated or anonymous users only the read/insert access you intend. Do not use a service-role key in browser code.
4. In `index.html`, fill the public Supabase URL and anon/publishable key in `CHAT_CONFIG`.

Recommended production hardening: user auth or generated guest IDs, rate limits, profanity/spam moderation, report/block controls, message retention rules, and server-side validation.
