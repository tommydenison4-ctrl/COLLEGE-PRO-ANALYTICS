GRIDLOCK V39

WIN PROBABILITY
- Top GameCast win-probability card now contains BOTH frozen pregame and LIVE NOW.
- Live bar updates from the same state estimator shown in the live section.
- Prevents the frozen 92% pregame number from being mistaken for the current probability.

LIVE BETTING
- /api/odds?live=1 now requests the entire U.S. sportsbook region instead of only FanDuel/BetRivers.
- Preferred books are prioritized, but DraftKings, Caesars and any other available in-game book are retained.
- Live market selector chooses the most complete available book.
- If no bookmaker is returning an in-game market, GRIDLOCK says so explicitly.

FIELD
- Removed school-name/end-zone text; team logos remain.
- Removed abbreviation text from the possession logo chip on the field.
- Added perspective / rotateX sightline for a more broadcast-like 3D field.
- End-zone logos and home midfield logo remain.
